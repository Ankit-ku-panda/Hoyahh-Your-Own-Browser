Custom CSS

Style the browser toolbar and built-in homepage. Use #dashboard, #clock, #widgets, and CSS variables such as --accent. Remote CSS and fonts are blocked.

A style can hide controls. Ctrl+, always opens settings; “Reset appearance” clears custom styles.

Extensions

Load a trusted unpacked extension folder containing manifest.json. Chrome Web Store installation and some Chrome APIs are unsupported. MYNT can be selected as the new-tab page if it loads; its features are not guaranteed to work.

Browsing data

Tabs stay in memory. Website cookies and storage are cleared at startup and clean exit; crashes can leave data on disk until the next launch. Notes, appearance, shortcuts, and extension folder choices are saved separately. Extensions may also keep their own data.
